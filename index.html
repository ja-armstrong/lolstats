LoL stats

Ranked solo queue analysis built on Riot API data: one corpus of 9,584 matches / 96,104 player-games (NA), used both for population research and to score individual players against it.

Look up a player →

Search a Riot ID (Name#TAG) and get a report: per-game percentiles against the same role and rank band, a teammate differential that cancels team strength, and live weight sliders. Needs python server.py running - a static page cannot hold the API key.

Built reports →

Everyone looked up so far, scored against the same baseline.

Role impact explorer →

Filter the corpus by role and rank band, set your own metric weights, and watch AUC, win-rate-by-decile and the role × rank heatmap recompute. Backs the written analysis.

How the numbers are made

collect_matches.py harvests the ladder → prepare_features.py builds per-player metrics → build_reference.py freezes them into the baseline distributions → collect_player.py + build_player_web.py render one player against that baseline. Static files only: no backend, no API key in the browser.

Pages are generated locally and committed; reports only contain data Riot publishes, for players whose games were explicitly looked up. Not affiliated with Riot Games.
